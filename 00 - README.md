# TESTE-APC2026-2
TESTE DE REPOSITORIO APC20262 
Repositório dos trabalhos e projetos realizados na disciplina de Algoritmos e Programação de Computadores.

**Aula 01 — 10/08/2026**

Nesta aula tivemos uma introdução à disciplina. O professor apresentou o plano de ensino para o semestre e explicou sobre as linguagens de programação que iremos estudar ao longo da matéria.

A aula teve como objetivo despertar o interesse pela construção de programas de computador e mostrar a importância e a utilidade da programação no nosso dia a dia.

O primeiro programa apresentado foi o OctoStudio, que utiliza o Scratch como linguagem de programação. É uma linguagem visual baseada em blocos de código que se encaixam como peças de um quebra-cabeça, facilitando a criação de programas de forma mais intuitiva.

Utilizamos o OctoStudio para desenvolver um programa de apresentação pessoal, que foi apresentado para a turma.

**Aula 02 — 12/08/2026**

A segunda aula aconteceu no laboratório, onde fomos apresentados ao [Little Man Computer](https://www.101computing.net/lmc/) (LMC), um modelo que simula o funcionamento básico de um processador.

O LMC representa alguns dos principais componentes internos de um computador, como processador, memória e barramentos. Nele, podemos inserir instruções que são interpretadas pelo processador e observar os resultados produzidos pelo programa.

Também aprendemos sobre entrada e saída de dados, utilizando os recursos disponíveis no LMC para inserir informações e visualizar os resultados gerados pelo programa.

Juntamente com o LMC, foram apresentados os fluxogramas, que são representações gráficas utilizadas para demonstrar a sequência de passos e a lógica de um algoritmo. Eles ajudam a visualizar o funcionamento de um programa antes mesmo de sua implementação.
